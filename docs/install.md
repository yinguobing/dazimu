# 「大字幕」上门安装指南

> 目标：30 分钟内装好、校准好、教会长辈。

## 一、带什么

| 物品 | 说明 |
|---|---|
| 采集卡（MS2130 / Hagibis） | 带原装 USB 线 |
| HDMI 线 ×1 | 短一点，机顶盒 → 采集卡 |
| U 盘 | 里面放 `build/tvzoom.apk`（65 KB） |
| 遥控器 ×2 | 电视 + 机顶盒 |
| USB 延长线（可选） | 电视背面 USB 口不好插时用 |
| 笔记本（可选） | 万一要现场 adb 调试 |

APK 位置：`~/developer/tv-zoom/build/tvzoom.apk`

## 二、接线（只有两根）

```
机顶盒 ──HDMI──> 采集卡 ──USB──> 电视（蓝色 USB 3.0 口）
```

- 电视的 HDMI 口**不用插**，画面和声音全部走 USB；
- 采集卡优先插**蓝色 USB 3.0 口**（黑色口也能用，实测帧率一样，但 3.0 带宽更稳）；
- 机顶盒音频设置：**解码 / PCM 立体声**，不要选透传。

## 三、装 APK（不需要电脑）

1. U 盘插电视；
2. 首页 → **全部应用 → 媒体中心 → U 盘 → 文件**；
3. 选中 `tvzoom.apk` → 确认 → 弹窗点**继续安装**；
4. 装完在「全部应用」里能看到**黄色“字”图标，名字叫「大字幕」**。

> 如果提示“暂不支持未知来源应用安装”，先把电视系统更新到最新版本。

## 四、第一次打开

1. 点图标，会连续弹两个权限：**相机**、**麦克风**，都选「允许」；
2. 画面出来，底部应该出现放大的字幕条；
3. 默认参数已经是调好的：**3.0× / 条高 20% / 取景框 10%**。

## 五、现场校准（约 1 分钟）

找一个有对白的频道，用遥控器：

| 键 | 作用 |
|---|---|
| ↑ / ↓ | 取景框上下（每档 2%） |
| ← / → | 倍数（2.0×–5.0×，默认 3.0×） |
| 菜单键 | 条高（8%–30%） |
| USB 按键（F3） | 一键打开大字幕，任意界面都有效 |

### USB 一键启动按键

老人在机顶盒界面想看大字幕时，不用再摸遥控器找 App：插一个 USB 按键，按一下就进来。

- 按键型号：普通可编程 HID 按键（VID 0x0483 / PID 0x5750），**默认发 F3**，不用改配置
- 实现：App 内建一个无障碍服务 `OpenKeyService`，只监听 F3，其他键全部放行
- 一次性开启，重启后仍有效：

```
设置 → 无障碍（辅助功能）→ 已下载的服务 → 大字幕 → 打开
```

或者用 adb：

```bash
adb shell settings put secure enabled_accessibility_services com.robin.tvzoom/com.robin.tvzoom.OpenKeyService
adb shell settings put secure accessibility_enabled 1
```

- 验证：`dumpsys accessibility | grep -A3 tvzoom` 应看到 `FLAG_REQUEST_FILTER_KEY_EVENTS`

### 开机自启

开机后等采集卡枚举出来就自动进入大字幕，**不需要人操作**。

- 收到 `BOOT_COMPLETED` 后每 8 秒探一次采集卡，最多 20 次（约 160 秒），探到才开
- 插拔采集卡（`USB_DEVICE_ATTACHED`）也会立刻触发
- 启动动作**由无障碍服务发起**：无障碍服务被系统绑定，不受 Android 的后台启动限制
  （实测：在未授予 `SYSTEM_ALERT_WINDOW` 的情况下也能正常拉起）
- 所以「开机自启」和「USB 一键启动」依赖同一个开关——无障碍开着，两个都工作

> 万一没开无障碍，还有一层兜底：`adb shell appops set com.robin.tvzoom SYSTEM_ALERT_WINDOW allow`

### 重启后的行为（实测）

- 无障碍服务**会**在开机后自动重新绑定，USB 按键和开机自启恢复可用
- 曾经出现过一次「重启后服务没绑上、按键失效」：开机广播里在主线程探测相机（冷启动可能卡几秒），
  和系统绑定无障碍服务抢主线程。现在 `BootReceiver` 改成 `goAsync()` + 后台线程 + 延迟 2.5 秒，
  给系统留出绑定窗口
- 电视每次重启后会关闭 HDC 调试，需要重新在开发者选项里打开（和 App 无关）
- 遇到过一次「遥控器按一下跳好几个选项」：当时 USB 键盘的输入节点刚从 `event6` 变成 `event0`
  （重新枚举），系统里残留了异常状态。重启后自己就好了，和无障碍服务无关
- 万一再遇到输入异常，先试：拔掉 USB 按键、重启电视；不用改 App



- 注意：`input keyevent KEYCODE_F3` 模拟**测不出来**，安卓的按键过滤只认真实硬件事件，必须实物按


**交互原则**（改功能时请遵守）

- 一个键只有一个含义，不做长按/双击/组合键——老人记不住第二层
- 任何参数变化都要有**看得见的大号反馈**，不能只在后台改数字
- 到边界时明确告诉老人「已是最小 2.0×」，而不是默默不响应
- 功能被关闭时要留一个常驻提示，避免「画面没变化 = 坏了」

调到「字幕完整落在放大条里、字够大」为止，参数会自动保存。

## 六、走之前必须验收的三件事

1. **断电重启**：拔电视插头 → 重新插 → 打开「大字幕」→ 确认还是机顶盒画面（不是室内摄像头画面）；
2. **换个片源**：宽银幕电影字幕会更靠上，确认她会用 ↑↓ 调；
3. **声音**：有声、口型基本对得上、遥控器音量能调。

## 七、教长辈三件事（建议写张纸贴在电视旁）

> **看大字**：点黄色「字」
> **字太小**：按 ← →
> **字跑了**：按 ↑ ↓

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 黑屏 +「未检测到采集卡，正在重试」 | 开机时 USB 枚举漏了（卡在总线上但相机服务没建节点） | **拔插一次 USB**，App 会在 3 秒内自动接上，不用重开 |
| 黑屏 +「未检测到信号」 | 机顶盒没开 / HDMI 松 | 检查机顶盒和线 |
| 没有声音 | 机顶盒设了透传 / 静音 | 改「解码」，查音量 |
| 画面轻微顿挫 | 采集卡 30fps 上限 | 正常，消不掉 |
| 打开是室内画面 | 选中了内置摄像头 | 确认装的是最新 APK |
| 提示「正在重连」 | 采集卡掉线 | 等 3 秒自动恢复，不行就拔插 USB |

## 九、回来之后

- 她用几天后，问一下倍数/条高是否要微调，改默认值重新打包；
- 如果她经常断电重启后不会开 App，可以考虑加「开机自启」。
