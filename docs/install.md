# 「大字幕」上门安装指南

> 目标：30 分钟内装好、校准好、教会长辈。

## 一、带什么

| 物品 | 说明 |
|---|---|
| 采集卡（MS2130 / Hagibis） | 带原装 USB 线 |
| HDMI 线 ×1 | 短一点，机顶盒 → 采集卡 |
| U 盘 | 里面放 `build/tvzoom.apk`（65 KB） |
| 遥控器 ×2 | 电视 + 机顶盒 |
| USB 延长线（可选） | 电视背面 USB 口不好插时用 |
| 笔记本（可选） | 万一要现场 adb 调试 |

APK 位置：`~/developer/tv-zoom/build/tvzoom.apk`

## 二、接线（只有两根）

```
机顶盒 ──HDMI──> 采集卡 ──USB──> 电视（蓝色 USB 3.0 口）
```

- 电视的 HDMI 口**不用插**，画面和声音全部走 USB；
- 采集卡优先插**蓝色 USB 3.0 口**（黑色口也能用，实测帧率一样，但 3.0 带宽更稳）；
- 机顶盒音频设置：**解码 / PCM 立体声**，不要选透传。

## 三、装 APK（不需要电脑）

1. U 盘插电视；
2. 首页 → **全部应用 → 媒体中心 → U 盘 → 文件**；
3. 选中 `tvzoom.apk` → 确认 → 弹窗点**继续安装**；
4. 装完在「全部应用」里能看到**黄色“字”图标，名字叫「大字幕」**。

> 如果提示“暂不支持未知来源应用安装”，先把电视系统更新到最新版本。

## 四、第一次打开

1. 点图标，会连续弹两个权限：**相机**、**麦克风**，都选「允许」；
2. 画面出来，底部应该出现放大的字幕条；
3. 默认参数已经是调好的：**3.0× / 条高 20% / 取景框 10%**。

## 五、现场校准（约 1 分钟）

找一个有对白的频道，用遥控器：

| 键 | 作用 |
|---|---|
| ↑ / ↓ | 取景框上下（每档 2%） |
| ← / → | 倍数（2.0×–5.0×，默认 3.0×） |
| 菜单键 | 条高（8%–30%） |


### 开机自启

开机后等采集卡枚举出来就自动进入大字幕，**不需要人操作**。

- 收到 `BOOT_COMPLETED` 后每 8 秒探一次采集卡，最多 20 次（约 160 秒），探到才开
- 插拔采集卡（`USB_DEVICE_ATTACHED`）也会立刻触发
- 后台启动界面在 Android 10+ 默认被拦，需要给一次悬浮窗豁免：

```bash
adb shell appops set com.robin.tvzoom SYSTEM_ALERT_WINDOW allow
```

> 这条命令在安装时跑一次即可，之后重启也有效。装的时候如果用 adb 安装，顺手就带上了；
> 如果只用 U 盘装，需要找机会开一次 HDC 跑这条，否则开机会停在桌面而不是大字幕。

### 重启后的行为（实测）

- 开机自动进入大字幕（采集卡在的话），不需要任何操作
- 电视每次重启都会关闭 HDC 调试，需要重新在开发者选项里打开（和 App 无关）
- 遇到过两次输入异常（遥控器按键重复），排查结论：与 App 无关的一次是 USB 复合设备重新枚举后
  的残留状态，重启自愈；与 App 有关的一次是无障碍按键过滤的系统 bug（v1.7 已弃用该功能）


### USB 一键启动：已放弃

试过两条路，都走不通：

1. **无障碍按键过滤**：这台电视的 ROM 在服务声明 `flagRequestFilterKeyEvents` 后，
   会把每个按键投递两次（服务侧只收到一次，界面走两格）。开着过滤，老人按一下方向键会跳好几格。
2. **媒体键 + MediaSession**：需要把 USB 按键改成播放/暂停键，但改完设备发不出数据，
   而且这台电视的媒体键路由被华为音乐占着。

结论：不值得为了“少按两下遥控器”去对抗系统行为。**USB 按键不再支持。**

目前的启动方式：开机自动进入大字幕；回首页后从「大字幕桌面」的第一个按钮进入（1 次点击）。
