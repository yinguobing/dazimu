# 「大字幕」上门安装指南

> 目标：30 分钟内装好、校准好、教会长辈。

## 一、带什么

| 物品 | 说明 |
|---|---|
| 采集卡（MS2130 / Hagibis） | 带原装 USB 线 |
| HDMI 线 ×1 | 短一点，机顶盒 → 采集卡 |
| U 盘 | 里面放 `build/tvzoom.apk`（65 KB） |
| 遥控器 ×2 | 电视 + 机顶盒 |
| USB 延长线（可选） | 电视背面 USB 口不好插时用 |
| 笔记本（可选） | 万一要现场 adb 调试 |

APK 位置：`~/developer/tv-zoom/build/tvzoom.apk`

## 二、接线（只有两根）

```
机顶盒 ──HDMI──> 采集卡 ──USB──> 电视（蓝色 USB 3.0 口）
```

- 电视的 HDMI 口**不用插**，画面和声音全部走 USB；
- 采集卡优先插**蓝色 USB 3.0 口**（黑色口也能用，实测帧率一样，但 3.0 带宽更稳）；
- 机顶盒音频设置：**解码 / PCM 立体声**，不要选透传。

## 三、装 APK（不需要电脑）

1. U 盘插电视；
2. 首页 → **全部应用 → 媒体中心 → U 盘 → 文件**；
3. 选中 `tvzoom.apk` → 确认 → 弹窗点**继续安装**；
4. 装完在「全部应用」里能看到**黄色“字”图标，名字叫「大字幕」**。

> 如果提示“暂不支持未知来源应用安装”，先把电视系统更新到最新版本。

## 四、第一次打开

1. 点图标，会连续弹两个权限：**相机**、**麦克风**，都选「允许」；
2. 画面出来，底部应该出现放大的字幕条；
3. 默认参数已经是调好的：**3.0× / 条高 20% / 取景框 10%**。

## 五、现场校准（约 1 分钟）

找一个有对白的频道，用遥控器：

| 键 | 作用 |
|---|---|
| ↑ / ↓ | 取景框上下（每档 2%） |
| ← / → | 倍数（2.0×–5.0×，默认 3.0×） |
| 菜单键 | 条高（8%–30%） |
| OK | 放大条开关（关闭时右下角有常驻提醒） |

调到「字幕完整落在放大条里、字够大」为止，参数会自动保存。

## 六、走之前必须验收的三件事

1. **断电重启**：拔电视插头 → 重新插 → 打开「大字幕」→ 确认还是机顶盒画面（不是室内摄像头画面）；
2. **换个片源**：宽银幕电影字幕会更靠上，确认她会用 ↑↓ 调；
3. **声音**：有声、口型基本对得上、遥控器音量能调。

## 七、教长辈三件事（建议写张纸贴在电视旁）

> **看大字**：点黄色「字」
> **字太小**：按 ← →
> **字跑了**：按 ↑ ↓

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 黑屏 +「未检测到采集卡，正在重试」 | 开机时 USB 枚举漏了（卡在总线上但相机服务没建节点） | **拔插一次 USB**，App 会在 3 秒内自动接上，不用重开 |
| 黑屏 +「未检测到信号」 | 机顶盒没开 / HDMI 松 | 检查机顶盒和线 |
| 没有声音 | 机顶盒设了透传 / 静音 | 改「解码」，查音量 |
| 画面轻微顿挫 | 采集卡 30fps 上限 | 正常，消不掉 |
| 打开是室内画面 | 选中了内置摄像头 | 确认装的是最新 APK |
| 提示「正在重连」 | 采集卡掉线 | 等 3 秒自动恢复，不行就拔插 USB |

## 九、回来之后

- 她用几天后，问一下倍数/条高是否要微调，改默认值重新打包；
- 如果她经常断电重启后不会开 App，可以考虑加「开机自启」。
